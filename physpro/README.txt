PHYSPRO - physics formula solver for the TI-84 Plus CE
=======================================================
Files (send ALL 5 to the calculator's Archive):
  PHYSPRO.8xp   the app
  PXFA.8xv PXFB.8xv   formula data
  PXFONT.8xv    fonts
  clibs.8xg     standard CE C libraries (skip if you already have them)

Install:
1. Install TI Connect CE (free) from education.ti.com.
2. Send all 5 files to Archive.
3. On OS 5.5 or newer, C programs need the arTIfiCE jailbreak to run:
   https://yvantt.github.io/arTIfiCE/  (follow its guide), then launch PHYSPRO.

Use:
- Pick a topic. "Fill in" pages: type what the problem gives, leave the rest blank,
  press GRAPH. It solves every missing value; ENTER on an answer shows the work.
- Or pick one formula, leave one box empty, press GRAPH.
- MODE switches between light and dark.
